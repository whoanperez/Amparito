Amparito · Hackathon Colsubsidio × 30X · Arquitectura C4

De Amparito base a Amparito+

La misma app de venta automatizada de seguros, antes y después de los cambios de la rama feature/amparito-plus. El backend del chat no se rompió: todo lo nuevo es aditivo. Modelo C4: Contexto → Contenedor → Componente.

Ya existía — base (v1) Nuevo o modificado — Amparito+ (v2)
v1 · base

Chat que recomienda por palabras clave

Claude Haiku con tool-use cierra la venta end-to-end (cotiza, cumplimiento Art. 9, certificado mock), pero la recomendación sale de un matcher de palabras clave sin explicar el porqué.

v2 · Amparito+

Motor de propensión explicable + capa del porqué

Un scorecard determinista sobre datos reales produce la recomendación con reason codes; se hace visible el porqué, se añade pull-first + anti-venta, voz Gemini Live (tras flag) y modo demo offline.
